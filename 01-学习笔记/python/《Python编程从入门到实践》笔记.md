# 代码格式PEP8
- 缩进：每级缩进使用四个空格，设置文本编辑器使其将制表符转换为4个空格
- 行长：建议代码不超过80字符，注释不超过72字符。可在文本编辑器中设置视觉标志
- 空行
- 在比较运算符的两边各加一个空格
- `print()`函数中的分行：
	每行末尾加引号，第二行及以后在行首加引号并缩进

# 第二章 变量和简单数据类型
## 1.变量
- 变量是标签，指向特定的值
- 变量名只能包含字母，数字，下划线，不能以数字开头
- 利用`traceback`找到错误
## 2.字符串
- 字符串是一系列字符，用引号括起，单双引号均可
- 使用 *方法* 修改字符串的大小写 (方法是python可对数据执行的操作）`.title()，.upper()，.lower()`
- 在字符串中使用变量：在前引号前加`f`，将要插入的变量放入花括号内
- 添加空白：使用`\t，\n`
- 删除空白：使用`.strip(),lstrip(),rstrip()`
- 常见语法错误：在单引号括起的字符串中包含撇号
- 创建多行字符串：
	将第一行字符串赋给一变量，然后逐行使用`+=`运算符
## 3.数
- 整数，浮点数
- 打印使用下划线分组的数字时，下划线不会被打印
## 4.注释
- 用`#`编写注释，注释不会被执行

# 第三章 列表简介

- 列表是一系列按特定顺序排列的元素
- 用方括号[]表示，并用逗号分隔其中的元素
## 1.列表元素的访问，修改，添加，删除
- 访问和修改：使用索引（列表第N个元素的索引为N-1）
- 添加：使用*方法*
	- `.append()`在末尾添加
	- `.insert()`在指定位置添加，如`motorcycles.insert(0,'yamaha')
- 删除：
	- 根据索引号删除：
		- 使用`del`语句
		- 使用方法`.pop()`删除并返回删除值，无参数时返回默认为最后一个元素
	- 根据值删除：使用方法`.remove()`
		方法`.remove()`只能删除第一个特定的值，若要删除多个需要使用循环
## 2.组织列表
- 排序：
	- 使用方法`.sort()`永久排序。无参数按字母顺序排序，若有参数`reverse = True`则按相反顺序排序
	- 使用函数`sorted()`临时排序。同样也可使用参数`reverse = True`
- 反转列表顺序：使用方法`.reverse()`
- 确定列表长度：使用函数`len()`

# 第四章 操作列表
## 1.遍历整个列表
- 使用`for`循环遍历列表
## 2.避免缩进错误
python根据缩进判断代码行之间的关系，常见错误有：
- 忘记缩进
- 不必要或错误的缩进
- 遗漏冒号
## 3.创建数值列表
- 使用`for`循环和函数`range()`
	`range(2,11,3)`三个参数分别为初值，终值（小于），步长，省略步长时默认为1
- 使用列表解析
	`squares = [value**2 for value in range(1,11)`
## 4.使用列表的一部分——切片
`players[1:4]`方括号中两个索引分别为起始索引和终止索引（不包含）
- 省略起始索引[ :4]，默认起始于列表开头
- 省略终止索引[1: ]，默认终止于列表末尾
- 省略起始和终止索引[ : ]，默认从开头到结尾。可实现列表的复制
		辨析`a = players[:]`和`a = players`前者实现复制，两变量分别指向两个列表；而后者使两变量指向同一个列表
## 5.不可变的列表——元组
- 元组使用圆括号而非中括号表示
	如果元组只包含一个元素，必须在这个元素后加逗号，如`dimention = (1,)
- 元组中的元素不能被修改，但指向元组的变量可以被重新赋值
	`dimention[0] = 2`错误，但`dimention = (2,)`合法

# 第五章 if语句
## 1.条件测试
if语句的核心为条件测试（一个值为`True`或`False`的表达式）
- 条件运算符` == `,` != `,` > `,` < `等
- 检查多个条件：使用关键字`and`,`or`
- 检查特定值是否在列表中：使用关键字`in`,`not in`
- 检查列表是否为空
	`if`语句将列表名作为条件表达式时，列表不为空时返回`True`,列表为空时返回`False`
	如`if requested_toppings:`
## 2.if语句
- 只执行一个代码块时，使用`if-elif-else`结构
	依次检查每个条件测试，直到遇到通过了的条件执行其后的代码并跳过剩余测试
- 需要执行多个代码块时。使用一系列独立的`if`语句

# 第六章 字典
- 字典是一系列键值对
- 用花括号{}表示，键与值之间用冒号分隔，键值对之间用逗号分隔
## 1.使用字典
- 访问修改字典中的值和添加键值对：使用键，如`alien_0['color']`
- 删除键值对：使用`del`语句，指定字典名和要删除的键,如`del alien_0['color']`
- 使用方法`get()`访问值
	`point_value = alien_0.get('points',No point value assigned.')`
	- `get()`第一个参数指定键，第二个参数为指定键不存在时的默认返回值（可选，默认为`None`)
	- 若字典中有指定键，返回相应值；若无，返回默认值
## 2.遍历字典
- 遍历所有键值对:使用方法`.items()`和`for`循环
	`for key, value in alien_0.items()`
- 遍历所有键：使用方法`.keys()`返回一个键列表
- 遍历所有值：使用方法`.value()`返回一个值列表
## 3.嵌套
- 列表字典：将字典作为列表元素`aliens = [alien_0, alien_1]`
- 在字典中存储列表：将列表作为键的值
- 在字典中存储字典：将字典作为键的值

# 第七章 用户输入和`while`循环
## 1.函数`input()`
- 参数为要向用户显示的prompt
- 程序格式：
	- 在提示末尾添加一个空格
	- 提示超过一行（多行字符串）时，先将提示赋给变量，再将变量传递给函数`input()`
- `input()`获取的输入为字符串
	若需要返回数值类型，需用函数`int()`转换
## 2.`while`循环
- 循环条件：
	- 条件表达式为`True`时while循环执行，为`False`时循环停止
		for循环针对集合中的每个元素执行一次
	- 设置一个初始值为`True`的使用标志
		在后面程序中对使用标志的值进行修改
- 循环的退出：
	- 语句`break`退出整个循环
	- 语句`continue`只跳过本次迭代余下代码，然后继续下一次迭代
- 避免无限循环
	如果程序陷入无限循环，可按`Ctrl+C`或关闭终端
- 应用：使用while循环处理列表和字典
	- 在列表间移动元素
		使用`while unconfirmed_users:`判断原列表元素是否全部移除
		使用`.pop()`取出原列表元素，`.append()`将原列表元素添加至新列表
	- 删除为特定值的所有列表元素
		使用`while 'cat' in cats ：`判断特定值是否还在列表中
		使用`.remove()`移除特定值元素
	- 使用用户输入填充字典

# 第八章 函数
## 1.定义函数
- 定义：使用关键字`def`，包含函数名、形参，以冒号结尾
- 函数体
	- 第一行应为文档字符串，描述函数是做什么的，用三引号括起
	- 可使用`return`语句返回值
## 2.传递实参
- 位置实参：实参顺序与形参顺序相同
- 关键字实参：明确指出实参对应的形参名，对顺序无要求
- 默认值：在函数定义中为形参指定默认值
	- 函数调用时提供了相应实参则传递实参，若未提供相应实参则传递默认值
	- 形参列表中必须先列出没有默认值的实参，再列出有默认值的实参
-  列表
	若需要禁止函数修改列表，可传递列表的副本，如`function_name(list_name[:])`
## 3.传递任意数量的实参
- 接纳任意数量实参的形参必须放在函数定义的最后
- 创建元组形参接收实参
	`def make_pizza(*toppings)`形参名中的`*`让python创建名为`toppings`的空元组，并将接收到的值封装到这个元组中
- 创建字典形参接收形参
	`def make_pizza(**toppings)`形参名中的`**`让python创建名为`toppings`的空字典，并将接收到的所有名称值对放到这个字典中
## 4.将函数存储在模块中
- 模块的导入
	- 导入整个模块：`import pizza`
		可使用`as`给模块起别名`import pizza as p`
	- 导入特定函数：`from pizza import make_pizza`
		可使用`as`给函数起别名`from pizza import make_pizza as mp`
	- 导入模块中所有函数：`from pizza import *`
- 函数的调用
	- 若只导入了模块：须同时指定模块名和函数名`pizza.make_pizza(16,'pepperoni')
	- 若直接导入了函数：只需指定函数名`make_pizza(16,'pepperoni')`
## 5.函数编写格式规范
- 编写文档字符串
- 形参指定默认值和使用关键字实参时，等号两边不要有空格
- 若形参长度太长，分行时需缩进两层
- 多个函数间空一行
- `import`语句放在文件开头

# 第九章 类
## 1.类的创建
```
class Car:
	'''一次模拟汽车的简单尝试'''
	
	def __init__(self,make，model):
		'''初始化属性'''
		self.make = make
		self.model = model
		
	def get_descriptive_name(self):
		'''描述信息'''
		print(f"{self.make} {self,model}")
```
- 类的定义
- 文档字符串：描述类的功能
- 方法：类中的函数
	- `__init__()`在创建实例时自动调用，开头结尾各有两个下划线
	- 所有方法都必须包含形参 `self`
- 属性：类中的变量
	- 以`self.`为前缀
	- 可供类中的所有方法使用，可以通过类的所有实例访问
	- 默认值：不通过形参定义的属性，在方法`__init__()`中为其指定默认值
	- 修改属性的值
		可通过实例访问修改，通过方法进行修改
	- 属性可以是其他类的实例
## 2.类的使用
- 创建实例
	- `my_dog = Dog('Chalie')`
- 访问属性：`my_dog.name`
- 调用方法：`my_dog.sit()`
## 3.类的继承
子类继承父类的属性和方法，同时可定义自己特有的属性和方法
```
class ElectricCar(Car):
	'''电动汽车的独特之处'''
	
	def __init__(self,make,model):
		'''先初始化父类属性，在初始化电动汽车的特有属性'''
		super().__init__(make,model)
		self.battery_size = 75
```
- 定义：创建子类时，父类必须包含在当前文件中，并在圆括号内指定父类名称
- 方法
	- 父类方法的复用：函数`super()`调用父类的方法`__init__()`初始化属性
		`__init__()`为子类的方法，所以必须通过函数`super()`才能访问父类方法
	- 父类方法的改写：在子类中定义相同名称的方法覆盖父类方法
## 4.类的导入
python可将类存储在模块中，然后再主程序中导入需要的模块或其中的类
- 直接导入类：`from car import Car，ElectricCar`
	可使用别名`from car import Car as C`
- 导入整个模块：`import car`
	可使用别名`import car as c`
- 导入模块的所有类（不推荐）：`from car import *`
## 5.Python标准库
安装Python时就包含的一组模块，可直接导入
## 6.类编写格式规范
- 类名，实例名，模块名
	- 类名使用驼峰命名法，每个单词首字母大写，不使用下划线；
	- 实例名和模块名小写，使用下划线
- 类定义后应有文档字符串，描述类的作用
- 空行：使用一个空行分隔方法，两个空行分隔类
- 模块的导入：先导入标准库模块，再导入自己编写的模块
